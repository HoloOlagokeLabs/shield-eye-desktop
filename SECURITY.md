# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 1.0.0   | ✅        |

## Reporting a Vulnerability

Do not open a public issue for security vulnerabilities.
Please allow up to 48 hours for an initial response.
Contact: [report@holoolagoke.com](mailto:report@holoolagoke.com)

## Scope

- Local database encryption issues
- PRAGMA key handling vulnerabilities
- Update verification bypass
- Hash verification weaknesses
